# Фича: Направление движения автобуса в live

**Ветка:** `main` (под тоглами)
**Создана:** 2026-09-30
**Статус:** реализовано, тестируется под тоглами

## Контекст

**Зачем:** пользователи просят показывать, куда едет автобус. Раньше на карте был только
оранжевый кружок. Если он стоит у ТГУ, непонятно, «сейчас приедет» он или «уже уехал».

**Что отдаёт перевозчик** (Wialon, `POST https://service-tiv.ru/wialon/ajax.php`, `ids[]=794`):
`[{ x, y, description, icon }]`. **Курса, скорости, времени фикса и id нет.**
Проверено 2026-10-01 днём: на линии 4 автобуса, у всех **одинаковый** `description`
(«112С (Томск - Северный парк)») и `icon: "noname"`. Значит, различать автобусы можно
только по близости позиций, а `icon` ничего не кодирует.

**Маршрут с 2026-09 — одна петля:**
`Интернационалистов → (inLB, «из города») пр. Ленина … Лагерный Сад → Левитана … Три элемента →
Серебряный бор → (out, «в город») Анны Ахматовой … Набережная → Лагерный Сад … Интернационалистов`.

## Идея

Автобус едет либо «в город» (`out`), либо «из города» (`inLB`). Сравниваем, где он сейчас и
где был недавно, относительно линии маршрута:

- **Рядом только одно плечо** (Левобережный — только `inLB`; Маяк, Цветаевой, Набережная —
  только `out`) → направление видно по одной позиции.
- **Плечи на разных дорогах, но обе в радиусе** (Левитана: `inLB` в 50 м, дорога `out` в 140 м)
  → берём ближнее, если оно ближе на 60+ м.
- **Плечи на одной улице навстречу друг другу** (пр. Ленина, конечные) → смотрим, вдоль
  какого плеча автобус продвинулся.
- **Стоит** → прошлое направление. **Истории нет** → `null`: неправильная подпись хуже, чем никакая.

## Тоглы — как включить для теста

Всё новое закрыто двумя тоглами. Пока они выключены, поведение как до фичи.

1. **Бэкенд-флаг `liveDirection`** (по умолчанию `false`, в `feature_flags`). Включает
   фоновый опрос перевозчика (раз в 10 с, 05:30–00:30 по Томску) и показывает переключатель
   в настройках. Без флага позиции запрашиваются, только пока кто-то смотрит карту, как раньше.
   ```bash
   curl -X PUT https://severbus.ru/api/features -H "Authorization: Bearer $ADMIN_TOKEN" \
     -H 'Content-Type: application/json' -d '{"liveDirection":true}'
   ```
   ⚠️ Переключатель в настройках увидят все пользователи, но у каждого он выключен.
2. **Переключатель «Направление автобуса (бета)»** в настройках (localStorage,
   `severbus:settings.showBusDirection`, по умолчанию выключен). Включает стрелку, подпись
   и сопоставление маркеров по `id`.

`/api/live` отдаёт новые поля (`id`, `direction`, `bearing`) всегда: они только добавлены,
старые клиенты их игнорируют.

## Как устроено

### Бэкенд — `backend/src/services/live/`

- `geo.ts` — haversine, азимут, проекция точки на ломаную (локальные метры вокруг Томска).
- `direction.ts` — `detectDirection(now, before, prev)` по правилам из «Идеи». Константы:
  `NEAR_M = 200` (Маяк лежит в 160 м от OSM-линии), `OTHER_ROAD_M = 60`, `MIN_MOVE_M = 100`,
  продвижение вдоль плеча ≥ 50 % сдвига. Без `route-112s.json` всегда `null`, live работает как раньше.
- `tracker.ts` — `LiveTracker`: история позиций за 5 минут в памяти, стабильные `id`
  (по `description`, если он уникален в ответе, иначе жадно к ближайшему треку ≤ 1.5 км;
  трек живёт 10 минут без появлений), курс по свежему сдвигу ≥ 40 м за 2 минуты (держится
  ещё 5 минут на стоянке), направление.
  Точка «до» — **самая свежая, от которой автобус отъехал на 150+ м**, не старше 4 минут.
  С фиксированным окном в 2 минуты подпись после разворота на конечной отставала на минуту.
- `liveProxy.ts` — тот же запрос к перевозчику, ответ проходит через трекер. Кэш 9 с,
  параллельные запросы склеиваются в один. `startLivePoller()` — фоновый опрос под флагом.

### Линия маршрута — `backend/src/data/route-112s.json`

Собирается скриптом `node scripts/build-route-112s.mjs`:

- `out` — OSM relation 16313536 (Серебряный бор → Интернационалистов), 16.3 км;
- `inLB` — OSM relation 16313537 до Лагерного Сада + OSRM через Левитана … Три элемента
  до Серебряного бора, 15.5 км. В OSM (2023) обратный рейс ещё идёт по старой трассе.

Обе — ломаные, упрощённые до 5 м. Все остановки из `stops*Options.ts` лежат в пределах 50 м
от своей линии, кроме Маяка (159 м: в OSM разворот у Маяка записан после конечной, скрипт
эти пути пропускает). **Если перевозчик поменяет трассу — перезапустить скрипт и проверить.**

### Фронт

- `features/Settings` — `showBusDirection` в слайсе, вторая строка в `SettingsModal`
  (видна только при флаге `liveDirection`, неактивна без «Автобус на карте»).
- `widget/Map/assets/directionIcons.ts` — стрелка 64×64 (треугольник у верхнего края, при
  повороте обходит кружок автобуса) и плашки «в город» / «из города». Это SVG-картинки,
  а не `text-field`: глифы self-hosted тайлов не нужны.
- `widget/Map/ui/LiveBusLayer.tsx` — слой `livebus-arrow` (под иконкой, `icon-rotate` по
  `bearing`, `icon-rotation-alignment: map`) и `livebus-direction` (под автобусом). Свойства
  `bearing` / `directionIcon` кладутся в GeoJSON только при включённом тогле. Курс
  интерполируется по кратчайшей дуге.

## Проверено

- 18 тестов `npm test` в `backend/`: правила направления (Ленина на север и на юг, Левобережный,
  Маяк, стоянка, депо, обе конечные), стабильные id, курс, прогон круга по всей петле с шумом
  GPS ±15 м — 99 % верно, ошибки только в первые ~30 с после отъезда с конечной.
- Вживую 2026-10-01 днём на локальном бэке: у ЦУМа «в город» с курсом ~0°, на Дальне-Ключевской
  и пр. Ленина «из города» с курсом 272° → 181°. Стрелка поворачивается вместе с картой.
  Выключенный тогл или флаг → маркер как раньше.

## Edge Cases

- **Отстой на конечной** — подпись остаётся прошлой («в город» на Интернационалистов), пока
  автобус не уедет.
- **Автобусы стоят рядом и разъезжаются** — id могут поменяться местами (description у всех
  одинаковый), направление поправится через ~20–30 с.
- **Рестарт бэкенда** — история пропадает, на общих участках пару минут нет подписи.
- **Перевозчик вернёт вариант через Набережную (`inSP`)** — нужно третье плечо в
  `route-112s.json` и в `detectDirection`.
- **Перевозчик меняет трассу** — перезапустить `scripts/build-route-112s.mjs`.
